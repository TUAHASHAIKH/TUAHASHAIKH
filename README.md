## 🧰 What I Do

### 🤖 Agentic AI & LLM Systems
Multi-agent pipelines with LangGraph and FastAPI, semantic deduplication of agent output, and automated repair loops that patch, rebuild and re-test inside sandboxed containers before showing a result. I also work with MCP and agent tool use.

### 🌐 Full-Stack Web Development
Production web apps with React, Next.js, Node and TypeScript. I own features end to end, from requirements to deployment, and I've shipped real-time dashboards and published developer tooling as an npm CLI.

### 🔐 Backend Engineering & Security
Secure API design: passwordless JWT auth, domain-restricted onboarding, rate limiting, account locking and fraud checks, backed by PostgreSQL and Prisma.

### ⚙️ Systems & Low-Level Programming
C and C++ work including a compiler, an IoT sensor simulator, and an encrypted filesystem with journaling, XSalsa20-Poly1305 and Argon2id.

### 📊 Machine Learning & Data
End-to-end ML workflows with scikit-learn, pandas and Plotly, from EDA and preprocessing to model comparison dashboards, plus data analysis in Power BI and Tableau.
